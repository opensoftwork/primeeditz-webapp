## 🎯 Quick Summary

### The Core Promise

> **"See exactly where your project is — instantly."**

This eliminates phone calls, WhatsApp chaos, and "is my work ready?" anxiety.

### Design System

| Aspect          | Choice                        |
| --------------- | ----------------------------- |
| **UI Library**  | shadcn/ui + Radix UI          |
| **Styling**     | Tailwind CSS v4               |
| **Color Model** | OKLCH (perceptual uniformity) |
| **Methodology** | Sajid's Two-Step Depth System |
| **Typography**  | Inter                         |

### Key Decisions

| Decision        | Summary                                    |
| --------------- | ------------------------------------------ |
| **Upload Gate** | Trust-first: 5GB free, quotation expands   |
| **Onboarding**  | Inline project creation during signup      |
| **Theme**       | Dark + Light from Day 1 (OKLCH tokens)     |
| **Dashboard**   | Glanceable status board, not workflow maze |
| **Interaction** | One action, one click principle            |

### Target Users

| Role         | Experience Goal              |
| ------------ | ---------------------------- |
| **Client**   | VIP Treatment — "I'm valued" |
| **Employee** | Flow — "Just let me work"    |
| **Admin**    | Control — "Nothing slips"    |

### Primary Inspiration

- **Linear** — Command palette, keyboard-first, premium dark
- **Stripe** — Premium light mode with depth
- **Sajid** — Practical depth methodology
