# Story 12.4: Project Squad Creation Mutation

## User Story

**As a** Backend System,  
**I want** a mutation to create a project squad,  
**So that** the selected employees are formally linked to the project.

---

## Acceptance Criteria

- [x] `createProjectSquad` mutation accepts `projectId` and array of `{ employeeId, role }`.
- [x] Creates entries in the `squadMembers` table.
- [x] Updates project `actionState` to `assigned` if transitioning from `uploads_complete`.
- [x] Records entry in `statusHistory` for audit.

---

## Technical Implementation

### Files Created/Modified

- `convex/functions/admin/squads.ts`
  - `createProjectSquad` mutation
  - `getEligibleEmployees` query
  - `getProjectSquad` query
- `convex/functions/squads/mutations.ts`
  - `addSquadMember` mutation
  - `removeSquadMember` mutation
- `convex/schema.ts` - `squadMembers` table definition

### Key Decisions

- Squad members are linked to `projectId`, not a separate "squad" entity.
- Role is stored per squad member (e.g., "editor", "qc", "lead").
- `isLead` boolean flag identifies the project lead within the squad.
- Status history records squad assignment events.

- [x] Mutation creates squad member records
- [x] Project state transitions correctly
- [x] Status history updated on assignment
- [x] Query returns squad for a given project
- [x] Error handling for duplicate assignments
