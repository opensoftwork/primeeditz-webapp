# Story 12.1: Admin Assignment Page Infrastructure

## User Story

**As an** Admin,  
**I want** a dedicated `/assign` route for a specific project,  
**So that** I can focus on team building without clutter from the project detail view.

---

## Acceptance Criteria

- [x] Route `/projects/[projectId]/assign` exists and is protected for admins only.
- [x] Page loads project context (name, type, timeline).
- [x] Includes a "Back to Project" navigation.
- [x] Displays an empty state if no employees are assigned yet.

---

## Technical Implementation

### Files Created/Modified

- `src/app/(protected)/@admin/projects/[projectId]/assign/page.tsx`
- `src/components/modules/admin/projects/assign-team/index.tsx`
- `src/components/modules/admin/projects/assign-team/columns.tsx`
- `src/components/modules/admin/projects/assign-team/employee-data-table.tsx`
- `convex/functions/admin/squads.ts` (query: `getEligibleEmployees`)

### Key Decisions

- Route is protected via `@admin` parallel route structure.
- Page uses existing `getAdminProject` query for project context.
- Employee table is built with TanStack Table for filtering and sorting.
