# Story 25.1: Fix Fabricated QT Code in Builder Step 3

**Epic**: Epic 25 - Quotation ID & Display Fixes
**Status**: backlog
**Complexity**: Small (2 points)
**Created**: 2026-02-27
**Priority**: HIGH — Misleading QT codes shown to admin

---

## 📋 User Story

**As an** Admin,
**I want** the builder Step 3 to display the real quotation code (e.g., `QT-000003`),
**So that** I see the actual identifier that will appear on the sent quotation.

---

## ⚠️ Current State Analysis

### Root Cause: `step3-review-send/index.tsx`, line 135-136

```typescript
const code = quotationId
  ? `QT-${quotationId.slice(-6).toUpperCase()}` // ← BUG!
  : "DRAFT";
```

The Convex document `_id` is a hash (e.g., `j57d3xdbf82k`), so `slice(-6)` produces random hex like `81XDBF`. The real code generated by `generateQuotationCode()` is `QT-000003`.

### Where it's wrong:

| Location                                          | Shows       | Should Show                |
| ------------------------------------------------- | ----------- | -------------------------- |
| Builder Step 3 `reviewQuotation.code`             | `QT-81XDBF` | `QT-000003` or `NEW DRAFT` |
| Send Drawer (from builder) `reviewQuotation.code` | `QT-81X1MD` | `QT-000003` or `NEW DRAFT` |

## 🛠 Technical Implementation

### Fix line 135-136

**Before**:

```typescript
const code = quotationId
  ? `QT-${quotationId.slice(-6).toUpperCase()}`
  : "DRAFT";
```

**After**:

```typescript
// The quotation builder context should provide the saved quotation data
// which includes the real `code` from the database
const code = quotation?.code || "NEW DRAFT";
```

The builder context (`useQuotationBuilder`) fetches the full quotation when `quotationId` exists. Verify that `quotation` is available and has `.code`.

If the context doesn't expose the quotation directly, the `reviewQuotation` code should be built from the fetched data:

```typescript
const reviewQuotation = useMemo(() => {
  // Use actual code from saved quotation, or placeholder for new
  const code = existingQuotation?.code || "NEW DRAFT";
  return { code /* ... rest */ };
}, [existingQuotation /* ... */]);
```
