# Story 12.8: Client "Meet Your Team" Section

## User Story

**As a** Client,  
**I want** to see a "Meet Your Team" section on my project dashboard,  
**So that** I know who is responsible for my project.

---

## Acceptance Criteria

- [ ] Section appears on Client Project Detail page once a squad is assigned.
- [ ] Displays: Employee Name, Role, Avatar.
- [ ] Shows a brief intro like "Your creative team for [Project Name]".
- [ ] Does not reveal internal employee contact info.

---

## Technical Implementation

### Files to Create/Modify

- `src/components/modules/projects/detail/client-team-intro.tsx`
- `convex/functions/projects/queries.ts` (add: `getProjectTeamForClient`)

### Implementation Notes

- Query should only return: `name`, `role`, `avatar` (no email/phone).
- Component should be conditionally rendered when squad exists.
- Use a friendly card layout with avatars.

---

## Definition of Done

- [ ] Query returns limited team data
- [ ] Component renders on client dashboard
- [ ] Team only shown when squad is assigned
- [ ] No sensitive employee data exposed
