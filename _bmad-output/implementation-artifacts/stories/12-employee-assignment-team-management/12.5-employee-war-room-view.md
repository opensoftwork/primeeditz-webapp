# Story 12.5: Employee War Room View

## User Story

**As an** Employee,  
**I want** a dedicated "War Room" view for each project I'm assigned to,  
**So that** I can see my squad, project specs, and manage my handoffs in one place.

---

## Acceptance Criteria

- [x] Route `/assigned-work/[projectId]` displays the War Room.
- [x] Shows: Project Header (name, code, role badge), Squad Members sidebar, Production Feed.
- [x] Includes "Finalize Work" button to trigger deliverable submission.
- [x] Includes "Open Assets" navigation to folder view.

---

## Technical Implementation

### Files Created/Modified

- `src/app/(protected)/@employee/assigned-work/[projectId]/page.tsx`
- `src/components/modules/employee/assigned-work/[projectId]/index.tsx`
- `src/components/modules/employee/assigned-work/[projectId]/squad-member-card.tsx`
- `convex/functions/employees/projects.ts` (query: `getEmployeeProject`)
- `convex/employees.ts` (aggregated employee queries)

### Key Decisions

- War Room uses a 12-column grid layout (8 cols main, 4 cols sidebar).
- Squad sidebar shows all teammates with role badges.
- "Production Feed" area shows current action state and instructions.
- Reuses `ProjectSpecs` component from admin module.
