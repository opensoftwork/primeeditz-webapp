# Story 12.9: Availability Ribbon (Phase 2 - Design Only)

## User Story

**As an** Admin,  
**I want** to see a 30-day availability timeline for each employee,  
**So that** I can check for scheduling conflicts before assigning.

---

## Acceptance Criteria (Design Only)

- [ ] Document the data model for tracking employee availability (linked to project dates).
- [ ] Create a static mockup of the "Availability Ribbon" UI.
- [ ] Mark for implementation in a future sprint.

---

## Technical Design Notes

### Data Model Considerations

```typescript
// Potential schema addition
employeeAvailability: defineTable({
  employeeId: v.id("profiles"),
  date: v.string(), // ISO date
  status: v.union(v.literal("available"), v.literal("busy"), v.literal("off")),
  projectId: v.optional(v.id("projects")), // If busy, linked project
})
  .index("by_employee", ["employeeId"])
  .index("by_date", ["date"]);
```

### UI Concept

- Horizontal ribbon showing 30 days.
- Color-coded cells: Green (available), Amber (partial), Red (busy), Gray (off).
- Hover shows project name if busy.
- Integrates into employee table row.
