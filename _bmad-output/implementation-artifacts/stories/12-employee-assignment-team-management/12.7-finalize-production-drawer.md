# Story 12.7: Finalize Production Drawer

## User Story

**As an** Employee,  
**I want** a dedicated drawer to upload my final deliverables and mark production as complete,  
**So that** the project can move to Quality Control.

---

## Acceptance Criteria

- [x] Drawer opens from "Finalize Work" button.
- [x] Includes file drop zone for final deliverable upload.
- [x] Shows upload progress.
- [x] On success, transitions project to `deliverables_ready` state.

---

## Technical Implementation

### Files Created/Modified

- `src/components/modules/employee/assigned-work/[projectId]/finalize-work-drawer.tsx`

### Key Decisions

- Uses existing `generateUploadUrl` action for storage integration.
- Deliverables are stored in a dedicated path (not folder-scoped).
- Drawer includes confirmation step before finalizing.
- State transition is gated by status machine rules.
