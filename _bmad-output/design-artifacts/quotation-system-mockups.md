## Design System Notes

### Color Palette (Dark Theme)

| Element         | Color                        | Notes                   |
| --------------- | ---------------------------- | ----------------------- |
| Background      | `oklch(0.141 0.005 285.823)` | Deep dark               |
| Card Background | `oklch(0.21 0.006 285.885)`  | Slightly lighter        |
| Primary Accent  | `oklch(0.488 0.243 264.376)` | Blue/purple             |
| Success         | Green variants               | Approval, active states |
| Warning         | Amber variants               | Pending states          |
| Danger          | Red variants                 | Rejection, errors       |
| Border          | `oklch(1 0 0 / 10%)`         | Subtle white            |

### Typography

| Element  | Style                                        |
| -------- | -------------------------------------------- |
| Headings | Inter, Bold, uppercase, tracking-wider       |
| Body     | Inter, Regular/Medium                        |
| Numbers  | Mono font for alignment (prices, quantities) |
| Currency | Always show ₹ symbol, right-aligned          |

### Components

| Component | Notes                                             |
| --------- | ------------------------------------------------- |
| Cards     | Glassmorphic, subtle glow on hover                |
| Buttons   | Primary = gradient with glow, Secondary = outline |
| Inputs    | Dark background, subtle border, focus ring        |
| Tables    | Alternating row colors, hover highlight           |
| Badges    | Pill shape, color-coded by status                 |
